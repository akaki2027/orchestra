Agents

Every agent is a model, a soul and a role. Any agent may sit on any provider, local or hosted, and agents that do not depend on each other work simultaneously.

Models

Local models occupy your disk and can be pulled or removed here. Hosted models are selected, never downloaded. That distinction is the whole point, so this interface keeps them apart.

Settings

Credentials are held on this machine alone, in ~/.orchestra, readable only by you. They are never written into the repository and the page makes no third-party request.

Border policy

What may leave this machine. Enforced at the provider boundary, where every model call passes the same checkpoint. It governs the controlling agent, every sub-agent, and anything added later.

Declarable items
Detection is pattern-based. It reliably catches structured identifiers: addresses, numbers, keys, paths. It does not catch names, street addresses, dates of birth, or the fact that a passage concerns someone's health. For those, mark the agent interior only so its model can never change.

Inspection lanes

How many agents may work at once per provider. Hosted lanes run wide because they wait on the network; the local lane is narrow because models compete for memory. Because it is separate, a busy local lane never holds up hosted work.
