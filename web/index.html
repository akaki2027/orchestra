Privacy

What may leave this machine. Enforced at the provider boundary — every model call goes through the same guard, so this applies to the big agent, sub-agents, and anything added later.

What counts as sensitive

Detection is pattern-based. It reliably catches structured identifiers — emails, phone numbers, card numbers, API keys, IP addresses, file paths containing your username. It does not catch names, street addresses, dates of birth, or the fact that a paragraph is about someone's health. For those, mark the agent local only so its model can never change.

Parallelism

How many sub-agents may run at once per provider. Cloud lanes run wide because they are network-bound. The local lane is small because models compete for RAM — and because it is separate, a busy local lane never holds up your cloud agents.
